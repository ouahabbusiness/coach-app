# État du projet — 26/10/2026 (soir)

En ligne : https://ouahabbusiness.github.io/coach-app/ (GitHub Pages, publication automatique à chaque envoi sur `main`, tests obligatoires).

## Construit
**Séance et progression**
- Moteur de séance événementiel (séries, maintiens, repos réel, interruptions, douleur, corrections, fin partielle), reprise automatique.
- Lest : progression limitée aux charges réalisables (pièces 5, 5, 6, 12 kg ; kettlebells 6 et 12 kg séparées), gros saut → +2 répétitions d'abord.
- Au lancement : charge/répétitions ajustées d'après la dernière séance ; en séance : « Trop facile → monte » en direct.

**Coach**
- Entretien programme (20 questions) : zones du corps, priorité, tests, douleurs, sommeil, stress, travail, raison d'abandon, temps, créneau,
  fréquences, intensité, rigueur, durée, ton dur ou neutre. Option recommandée argumentée. Vérité sur la perte localisée.
- Programme A/B/C + re-test (semaine finale), courses progressives (+10 %/sem., fractionné détaillé, sortie longue, course chrono finale).
- Validation → modèles + planning du bloc, **placés dans les trous** de l'agenda, séjours adaptés au matériel.
- Rigueur appliquée aux imprévus : strict = pas de report ; militaire = ni report ni annulation, version courte ≥ 20 min (maladie/douleur toujours libres).

**Système de coaching (cahier des charges du 26/10)** — seuils = choix de conception ajustables, pas des lois
- Prescriptions en plages (force 3–6, muscle 6–12, assistance 10–15/20), réserve visée 3/2/1, échec seulement en dernière série si choisi.
- Double progression par exercice (`decide`) : augmenter / maintenir / réduire / observer ; effort non noté → confirmation sur 2 séances ; effort excessif → pas de hausse ; une séance isolée sous la plage ne change rien ; douleur → sécurité ; incrément réel du matériel.
- Journal des décisions (`decisions.log`) : avant/après, observations, règle, manques, réévaluation ; sauvegardé avant affichage.
- Séance libre / EMOM : travail effectué (jamais un maximum), incertitudes affichées, prochaine fois prudente.
- Contrôle avant séance (5 questions + alerte) ; retour après séance (prévu/fait, cible atteinte ≠ progression validée) ; répétitions jamais préremplies.
- Nutrition adaptative : développement +5 %, réduction −12 %, maintien = observation ; protéines 1,8–2,0 g/kg ; lipides ≥ 0,8 g/kg ; bilan sur 2 semaines (± 125 kcal).
- Statut des données (observée, déclarée, estimée, à confirmer), « bilan incertain », alerte sécurité en séance (112), suivi poids/calories facultatif.

**Cibles calculées**
- Eau 35 ml/kg + 0,5 L/h de séance ; calories Mifflin-St Jeor × activité, ajustées à l'objectif du programme et à la tendance du poids ; protéines 1,8 g/kg.
- Course : +10 % sur la plus longue récente, maintien si effort ≥ 9/10, baisse après pause.

**Nutrition et journée**
- Entretien nutrition (horaires, repas, aliments aimés, exclusions, compléments **déclarés** : créatine Creapure, whey Native Protimuscle).
- Plan du jour : repas avec quantités (valeurs moyennes, estimation), créatine après le petit-déj avec 300 ml d'eau, eau répartie,
  lumière du matin, dernier café, écrans coupés, coucher conseillé pour 8 h. Cocher l'eau remplit le compteur.
- Imprévu de repas (plat préparé par quelqu'un, resto, fast-food, sandwich, sauté) : estimation + repas suivants recalculés.

**Ma cuisine et courses**
- Produits personnels : photo du code-barres (lu dans le téléphone, ZXing) → valeurs Open Food Facts (seul le code est envoyé), ou étiquette recopiée ; alias (« prot », « shaker »).
- Plats maison : ingrédients + portions → valeurs par portion.
- « J'ai mangé » : texte libre (« 3 œufs, 80 g d'avoine, 1 portion riz-poulet ») ou favoris → kcal/protéines, photo de l'assiette en option ; inconnu jamais deviné ; la journée se recalcule.
- Liste de courses des 7 prochains jours depuis le plan (boîtes de 6 œufs, riz/pâtes en poids cru), par rayon, à cocher.

**Course en direct et matériel**
- « Go » : GPS en temps réel (distance, allure actuelle et moyenne, temps par km), carte OpenStreetMap du tracé, pause/reprise, écran gardé allumé.
- Modes : séance du jour guidée à la voix (échauffement, efforts, récups, allures tirées de l'historique ou repère d'effort), distance cible (demi-tour annoncé), libre.
- Course GPS = preuve pour le défi (sans photo) ; saisie manuelle : photo facultative, sinon « déclarée ».
- Matériel : inventaire, conseils d'achat notés pour toi (Game changer / Utile / Bonus, muscles, exercices débloqués, prix indicatifs), programme adapté au matériel possédé.

**Journée, prières, spots**
- Pesée du matin : plein écran à la première ouverture de la journée (« pas de balance aujourd'hui » avec raison).
- Prières : calcul sur le téléphone (adhan, Ligue islamique mondiale, Alost par défaut ou position actuelle), ± minutes par prière pour coller à l'app de la mosquée ; créneaux bloqués dans le planning ; lever 10 min avant Fajr ; repas jamais sur une prière ; prochaine prière sur l'accueil.
- Spots autour de moi (chez soi ou en vacances) : street workout, pistes, parcs (OpenStreetMap/Overpass, plan B Photon pour les parcs), itinéraire à pied dans Plans, « Courir ».
- Charges trop légères signalées par le coach (≥ 20 rép. avec réserve, ≥ 30 rép.) avec la charge suivante ou le matériel conseillé.
- Tapis de marche : pas du tapis ajoutés aux pas de la montre.

**Agenda**
- « Ma semaine » : travail, trajet, lever/coucher, engagements récurrents (ex. analyse Amazon), soirées, séjours avec matériel sur place.
- Indisponibilité ponctuelle → séance/course replacée le même jour sur le créneau libre le plus proche.

**Suivi**
- Défi de novembre : 6 habitudes, salle 4×/sem., course 3×/sem. ; chaque objectif réussi **compte seulement avec une photo du jour**.
- Page Winter Arc (montagne, sentier de 30 jours, série, semaines tenues).
- Poids (pesées, moyenne, tendance), mensurations (taille, hanches, cuisse), lecture (Atomic Habits, pages, journal avec photo).
- Onboarding 13 étapes (zone sombre) ; formule de calcul dans le profil ; objectifs versionnés ; export/import complet.

## Testé
- 173 tests automatisés (`npm test`) : moteur, stockage, défi, Winter Arc, preuves, lecture, cibles, lest, programme, imprévus, plan du jour, disponibilités, séjours.
- Navigateur de bureau (vue mobile) : accueil bleu, entretien programme complet → planning rempli, entretien nutrition jusqu'aux compléments,
  configuration sombre, fenêtre Calories.

## Non testé
- Sur iPhone : caméra des preuves photo, lecture d'un vrai code-barres photographié, GPS réel en course (testé avec un GPS simulé), annonces vocales, écran verrouillé, hors ligne réel, texte agrandi, lecteur d'écran.
- Plan du jour et « Ma semaine » affichés avec un vrai profil complet (testés par le moteur, pas encore à l'écran).

## Limites
- Notifications du matin : impossibles en web sans serveur ; prévues dans l'app native (notifications locales).
- Serveurs publics Overpass parfois saturés : seuls les parcs s'affichent alors.
- Valeurs nutritionnelles moyennes, imprévus de repas = ordres de grandeur. Aucune recommandation de complément.
- Règles d'entraînement générales, **non relues par un professionnel** ; catalogue sans média.
- Pas d'accès Apple Santé (fréquence cardiaque, Watch, balance) : nécessite l'app native (prochaine étape, xtool).
