# Feuille de route

- **Phase 1a (fait)** : moteur de séance, stockage local, mode séance, bilan, historique, export/import, style façon maquettes, défi de novembre.
- **Avant le 1er novembre** : hébergement HTTPS (avec accord) et installation sur l'iPhone ; test réel du chrono écran verrouillé.
- **Phase 1b (fait)** : onboarding persistant ; profil ; objectif versionné ; matériel ; planning de base.
- **Phase 1c (en partie fait)** : imprévus du planning et lien par identifiant faits ; reste : séance plus longue, reprise après interruption, rapport hebdo simple.
- **Phase 2** : nutrition, mesures, bilans croisés.
- **Phase 3** : app native xtool + HealthKit (preuve technique tôt : pas, sommeil, séances de la montre) ; module course.
- **Phase 4** : coach IA, journal des décisions, mode strict facultatif.
- **Phase 5** : relecture professionnelle, sécurité, accessibilité, tests physiques.
