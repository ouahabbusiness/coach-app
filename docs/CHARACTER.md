# Personnage évolutif — proposition (à valider par Hmidou)

## Demande (26/10/2026)
Un personnage de style manga (inspiration Hajime no Ippo / Dragon Ball) qui évolue par paliers (« comme super saiyan ») selon la progression.

## Contraintes
- **Droits d'auteur** : pas de Goku, Ippo ni de dessin dérivé reconnaissable. Personnage original.
- **Budget 0** : pas de génération d'images payante. Illustrations SVG dessinées dans le code, ou dessins fournis/commandés par Hmidou.
- **Honnêteté** : le personnage n'évolue que sur des faits enregistrés. Jamais de progression inventée pour motiver.
- **Corps** : pas d'analyse de photo, pas de « forme » déduite de l'apparence. Les mesures corporelles ne comptent que si elles sont mesurées et liées à l'objectif choisi.
- **Sécurité** : aucun palier perdu pour maladie, blessure, repos prescrit ou montre déchargée. Pas de récompense du dépassement dangereux.

## Critères possibles (à choisir)
1. Régularité : séances réalisées confirmées, semaines tenues.
2. Force : records confirmés sur des exercices repères (tractions strictes, pompes, maintien…).
3. Endurance : course (quand le module existera).
4. Corps (facultatif) : tendances de mesures réellement saisies ; jamais un pourcentage de graisse présenté comme exact.

## Paliers (noms originaux, exemple)
Base → Éveil → Aura → Aura II → Forme ultime. Chaque palier affiche ses conditions exactes et les données qui l'ont débloqué.
